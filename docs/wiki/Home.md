# Akuma — Demon Spawn for Windows

A compatibility patch and interface remaster for the English CD edition of
**Akuma — Demon Spawn (Lamentation Sword)**.

- [Online play](Online-Play.md): play Multi Play over the internet through a relay.
- [Hosting a relay](Hosting-a-Relay.md): run your own relay server (Linux or Windows).

Source code and releases: the main repository. Technical notes live in `docs/` (`netcode.md`,
`winsock-flow.md`) and `relay/PROTOCOL.md`.
